# Proyecto de Evaluación y Corrección de una Miniaplicación

Instalación:
Instalar la dependencia requerida:
pip install argon2-cffi

Ejecución:
Ejecutar el programa con:
python app.py

Notas:
Este proyecto utiliza datos ficticios con fines educativos. No pretende ofrecer seguridad completa para entornos de producción.

Durante el desarrollo del proyecto utilicé Microsoft Copilot para aclarar dudas sobre algunos conceptos de seguridad, entender mejor los requisitos y revisar posibles soluciones para el código. También me ayudó a corregir errores encontrados durante las pruebas. Todas las sugerencias fueron revisadas y verificadas antes de ser implementadas.
